## 2026-07-02　管理員後台改用 Thymeleaf（會員 / 小農維持 Vue）

### 背景
原本三種身分（會員 / 小農 / 管理員）前端都是 Vue 3 CDN SPA，透過 `/api/**` JSON API 溝通。
管理員後台屬於「表單密集、內部使用、無 SEO 需求」的 CRUD，改用 **Thymeleaf 伺服器端渲染**更貼合 Spring Security：
- 用 `sec:authorize` 依權限顯示畫面，**消除前端與後端重複的權限判斷**（原 `store.adminHasPerm`）。
- 後台表單自動帶 **CSRF**、登入改用標準 **formLogin**，攻擊面更小。
  會員 / 小農仍維持 Vue 不變。

### 調整內容

1. **新增 Thymeleaf 依賴與樣板**
    - `pom.xml`：`spring-boot-starter-thymeleaf`、`thymeleaf-extras-springsecurity6`、`org.webjars:bootstrap:4.2.1`。
    - `templates/back-end/admin/`：`login`、`dashboard`、`listAllMember`、`listAllFarmer`、`listReview`、
      `listAllAdmin`、`updateAdminInput`、`included-fragment`、`opError`。外觀採 Bootstrap 4.2.1（webjars）+ DataTables（CDN）。

2. **新增後台 MVC 控制器（`controller.view`，重用既有 Service）**
    - `AdminViewController`（登入頁 / 總覽）、`AdminMemberViewController`、`AdminFarmerViewController`、
      `AdminReviewViewController`（含證明文件圖片）、`AdminAccountViewController`（管理員 CRUD + 權限勾選）。
    - `AdminViewExceptionHandler`（`@ControllerAdvice`，僅套用後台、優先權最高）：把業務規則例外
      （如「不能修改其他超級管理員」）渲染成友善的 `opError` 頁，取代全域 `@RestControllerAdvice` 的純文字回應。

3. **安全設定拆分（`UserSecurityConfig`）**
    - 新增 `adminPageChain`（`@Order(0)`、`securityMatcher("/admin/**")`）：**formLogin + CSRF 開啟**，
      未登入導向 `/admin/login`；綁定專屬的 `DaoAuthenticationProvider`（用 `AdminUserDetailsService`）。
    - 逐權限授權：`/admin/admins/**` 需 `PERM_ADMIN`；`/admin/farmers|reviews/**` 需 `PERM_ADMIN|PERM_FARMER`；
      `/admin/members/**` 需 `PERM_ADMIN|PERM_MEMBER`。
    - 移除舊的 `adminChain`（`/api/admin/**`）；`defaultChain` 白名單移除 `/admin.html`、加入 `/webjars/**`。
    - 前台會員 / 小農三鏈維持關 CSRF（走 JSON），不受影響。

4. **移除舊的 Vue 後台與 REST 後台控制器**
    - 刪除 `static/admin.html`、`static/js/admin-app.js`，以及 `Admin*.js`
      （`AdminLogin`、`AdminDashboard`、`AdminMembers`、`AdminFarmers`、`AdminReviews`、`AdminAdmins`、`AdminGroupBuy`）。
      **保留 `DashboardLayout.js`**（會員 / 小農仍在用）。
    - 刪除 `AdminController`、`AdminUserController`、`AdminFarmerController`、`AdminReviewController`。
    - 前台頁尾「管理員入口」連結由 `admin.html` 改為 `/admin/login`。

### 影響
- 後台新網址：`/admin/login`（舊 `/admin.html`、`/api/admin/**` 皆已移除）。
- Service 層、DTO、Entity、會員 / 小農 Vue 前端**均不受影響**（後台重用同一套 Service）。
- 已知小限制：`store.js` 殘留的後台方法為無害死碼，可擇機清除。
